Blocks are arrows, not braces.

      
Gaug has its own shape. Here are six pieces of it, each small enough to read at a glance. The documentation covers the rest.

      

      

        
Blocks
Every block opens with an arrow and closes with a parenthesis. Statements end with a semicolon, so there are no braces to match.

        
var count = 0;
while (count < 3) -> (
    count += 1;
);

      

      

        
Functions
Declare with func. Parameter types follow a colon, and an optional return type follows the body after >>>.

        
func add(a: number, b: number) -> (
    return a + b;
) >>> number;

func log(message: string) -> ( print(message); );

      

      

        
Errors
There is no try and catch. An attempt block runs its body and hands any error to an except clause.

        
attempt () -> ( risky(); )
except (message: string) -> (
    print("caught:", message);
);

      

      

        
Classes
Call a class to make an instance. Members are private unless marked global, and a subclass uses override to replace a parent method.

        
class Entity -> (
    var health >>> int = 100;
    global func takeDamage(amount: int) -> (
        health -= amount;
    );
);

class Player extends Entity -> (
    override global func takeDamage(amount: int) -> (
        health -= amount * 1.1;
    );
);

var p = Player();
p.takeDamage(10);

      

      

        
Dictionaries
Keys are written in parentheses and read back with angle brackets that touch the name.

        
var d = {("name") = "Ada"; ("age") = 3};
d<"age"> += 1;

      

      

        
Types
Put !typechecker on the first line and annotations are checked. Generics and union types are supported.

        
!typechecker
var id >>> int | string = 42;
func identity<T>(value: T) -> ( return value; );

      

      

    

  


  

    

      
One parser, two ways to run.

      

        

          
Scripts are parsed once, then run by a bytecode fast path by default, or by the tree evaluator with --tree. Both should give the same output, so comparing them is a quick way to find a bug.

          
Add --safe to restrict the dangerous builtins. Memory is managed by an automatic garbage collector, and Gaug can be embedded in a C program through a handful of functions in gauglanguage.h.

        

        

          
gaug script.gaug
gaug --tree script.gaug
gaug --safe script.gaug

          
gaug_init(&config);
gaug_run_string(source);
gaug_shutdown();
