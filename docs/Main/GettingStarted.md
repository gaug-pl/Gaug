# Getting Started
To get started with Gaug, download the latest version in the [Installations](../installation) page.

## Run your first GaugScript!
Create a new .gaug script, name it `main.gaug`, and include this code inside of it:

```gaug
# main.gaug
print("Hello World!");
```

Run it with `./gaug main.gaug` or `gaug main.gaug`. Depending on your operating system.

The expected output should be:
```
> Hello World!
```
If not, then check if you renamed the gaug file and use that name to run the main.gaug file.
