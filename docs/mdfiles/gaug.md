# Gaug

Gaug is a lightweight, modern programming language designed to keep programming simple, readable, and enjoyable.

::: info
If you have not already. Please read "[Why Gaug?](whyGaug)" to understand more about the language.
:::

## Syntax/Grammar
The syntax is very simple. To create a new variable. You can use either `var` or `const`. `var` stands for Variable, which can be changed anytime. While `const` stands for Constant. Which cannot be changed or else you will run into an error.

```gaug
var text = "Hello World!";
```

You also need to include a `;` at the end of every line except for loops and if conditions.
