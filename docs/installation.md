# Installation
Please head to [Installations](../installations.html) to check out new releases!

## Recommended Setup
- 64-bit Windows 10/11 PC (For Windows users)
- A modern dual-core processor
- 4 GB of RAM
- Around 100 MB of free space

## Requirements
- Anything from the last 2 decades

## Run your first script
Create a new .gaug file and add this script:
```gaug
print("Hello World!");
```

Then use gaugv1.exe to run it. If Gaug was installed properly you should see "Hello World!" in your console.
